#🛒 E-Commerce Web Application

A full-stack e-commerce web application developed using Python, Flask, SQLite, HTML, CSS, and JavaScript. The project provides core online shopping functionality including product browsing, product details, shopping cart management, and checkout.

##🚀 Features
Product listing and product details
Category-based product information
Add/remove products from cart
Shopping cart and order total calculation
Customer checkout and order placement
SQLite database integration
Responsive web interface

##🛠️ Technologies Used
Python
Flask
SQLite
HTML5
CSS3
JavaScript

##📂 Project Structure
E-Commerce-Web-Application/
├── app.py
├── database.py
├── ecommerce.db
├── requirements.txt
├── templates/
└── static/

##🎯 Project Objective
To build a practical web application that demonstrates Python backend development, Flask routing, database management, CRUD operations, session-based cart functionality, and frontend integration.
